Placeholder files **`booking-drizzle.sqlite`** and **`booking-typeorm.sqlite`** are committed as **empty (0 bytes)** so `data/` exists on GitHub. The first run of **`npm run dev`** or **`npm run db:smoke`** opens them with SQLite, creates the real database file on disk, and seeds **`rooms`**.

Your working copy will show the files as modified after you run locally; that is expected—do not commit those blobs unless you intend to.
